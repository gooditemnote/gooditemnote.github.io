# 좋은물건노트 — R008 상품번호 전용 검색 · 공식 HTML 카드

**2026-10-22 / 배포 전 전달본 (GitHub 배포하지 않음)**

## R008 변경 사항

- 검색은 **상품번호 전용**입니다. `001`·`002`처럼 번호로만 검색하며 상품명·특징·카테고리 검색은 지원하지 않습니다.
- 검색창에는 번호 예시를 표시하고 모바일 숫자 키보드를 요청합니다. 최대 4자리(현재 등록 가능 번호 001~9999).
- 번호 입력 중 `0`·`00` 등은 **앞자리 일치** 목록이 보이고, `001`·`002` 입력 시 해당 번호 카드가 표시됩니다.
- 숫자가 아닌 문자 입력 시 결과 없음 안내가 표시됩니다. 검색 초기화, 정렬 및 더보기 동작은 유지합니다.
- **001·002 쿠팡 파트너스 iframe HTML, 제휴 주소/속성, 상품데이터 파일 및 번호별 HTML 원본은 변경하지 않았습니다.**
- 이전 R004·R005·R006의 통합검색 정책은 기록으로 보존하며, 공개 검색 동작은 R008 규칙을 우선 적용합니다.


## 적용된 상품

| 상품번호 | 공개 상품명(검색용) | 쿠팡 파트너스 HTML 원문 |
|---|---|---|
| 001 | 서랍형 책상 정리함 | `partner-html/001.html` (`https://coupa.ng/cqkhQb`) |
| 002 | 철제 시스템 드레스룸 행거 | `partner-html/002.html` (`https://coupa.ng/cqkhNh`) |

- **`index.html`이 실제 상품 목록**이며 `products.js`를 불러와 2개 상품을 표시합니다.
- `card-preview.html`도 실제 `products.js`를 읽으므로 번호/상품 링크가 혼동되지 않습니다.
- 두 공식 iframe 원문을 전달된 글자와 속성 순서까지 바꾸지 않고 각각 저장했습니다.
- 외부의 카드 테두리·상단 번호 배지에만 CSS가 적용됩니다. iframe에는 별도 CSS/속성을 추가하지 않습니다.
- 기존 001 텍스트/상품 식별자/등록일은 그대로 유지했습니다. 기존 `affiliateUrl` 값은 **현재 상품 카드에 표시되지 않는 과거 직접 링크 데이터**로 남겨 두었습니다. 실제 클릭은 새 `partnerHtml`의 공식 iframe 안에서만 이루어집니다.
- 002의 상품명/쿠팡 상품 ID/옵션 ID는 이전 R006 확인 기록을 사용했습니다. 공개명은 브랜드명을 제외했습니다.
- 001의 **새** `cqkhQb`가 기존 서랍형 정리함과 동일한 상품인지 이번 오프라인 검증에서는 확인하지 못했습니다. 실제 배포 전에 공식 카드 표시 상품을 직접 확인하세요. 002의 행거 매칭은 R006 검증 기록을 사용했습니다.
- 하단 쿠팡 파트너스 배너, 광고 고지, 상품번호 전용 검색, 정렬, 더보기 기능은 보존했습니다.

## HTML 원문 변경 금지 규칙

상품 추가 시 반드시 사용자가 제공한 해당 상품의 **쿠팡 파트너스 HTML 원문**이 필요합니다. URL/제휴 식별값/속성/폭/높이/속성 순서를 임의 수정, 축약, 재작성하거나 코드 안에 임의 속성을 추가하지 않습니다. 원본을 `partner-html/NNN.html`로 저장하고 `products.js`의 `partnerHtml`에 **문자열 그대로** 보관합니다. 외부 테두리, 상품번호 배지, 여백 등만 꾸밉니다.

`tools/register_product.py`는 **다음 신규 상품번호 등록**을 위한 도구입니다. 기존 번호에 공식 코드를 교체하는 경우 등록 도구의 덮어쓰기 차단을 무시하지 않고 검토·백업한 뒤 명시적으로 변경합니다.

검증 근거 및 주의사항은 `R007_001_002_APPLY.md`를 참고하세요. 이전 `R006_REVIEW.md`는 당시의 검토 이력으로 보관했습니다.
