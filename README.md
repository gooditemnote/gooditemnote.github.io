# 좋은물건노트 | GitHub Pages R004

유튜브 쇼츠에서 본 물건을 **상품번호**로 찾는 모바일 중심 상품 목록입니다.
회원가입, 자체 결제, 서버, 빌드 과정이 없는 정적 사이트이며 GitHub Pages에 수동 배포합니다.

## R004 확정 정책

1. 메인: 상품 목록 중심의 단일 페이지
2. 모바일: 한 줄에 2개
3. PC(900px 이상): 한 줄에 4개
4. 최초 표시: 12개
5. 더보기: 클릭마다 12개 추가, 마지막에는 남은 개수만
6. 정렬: 기본 최신 등록순, 오래된순, 상품번호순 선택 (변경 시 12개부터)
7. 검색: 번호, 상품명, 특징, 카테고리, 주의사항의 실시간 통합 검색
8. 카테고리: 실제 상품이 있는 것만 가로 탭으로 표시
9. 상품 카드: 이미지, 번호, 일반 상품명, 핵심 특징 한 문장, 구매 버튼 (가격 미표시)
10. 하단: 사이트명/한 줄 소개, 기존 쿠팡 광고 배너, 제휴 고지, 맨 위로 버튼

**공통 고정:** 공개 상품명 및 문구에 제품 브랜드명 사용 금지, 상품번호 고정·중복 금지, 쿠팡 파트너스의 실제 발급 링크만 구매 버튼 활성화, 확인된 사용권의 상품 사진만 사용, 광고 고지 유지, 사용자 직접 배포.

## GitHub Pages 수동 배포

1. 기존 `좋은물건노트` 전용 GitHub 저장소로 이동합니다. *Alliance Manager 저장소와 절대 혼합하지 않습니다.*
2. 이 압축파일을 풀고 **폴더가 아닌 내부 파일들**을 저장소 최상위에 업로드합니다. 폴더 `tools/` 및 `assets/`도 함께 업로드하세요.
3. 이미 업로드한 동일 파일은 교체하여 커밋합니다. `.nojekyll` 파일도 보존합니다.
4. `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택해 저장합니다.
5. 배포 후 저장소 주소가 `goodnote-shop`이라면 `https://깃허브아이디.github.io/goodnote-shop/`으로 접속합니다.

GitHub Pages를 처음 설정하는 경우 공개 저장소 설정과 Pages 지원 여부를 확인하세요.

## 신규 상품 등록: 채팅에서 링크만 전달

사용 예시:

> 좋은물건노트 R004 규칙대로 **002번 상품카드 만들어줘.** 상품 링크: https://www.coupang.com/vp/products/...

ChatGPT는 접근 가능한 쿠팡 상품 페이지에서 실제 상품 정보와 일부 리뷰를 분석해 공개 문구를 구성하고, 현재 배포용 파일에 새 카드 정보를 등록한 다음 수정 ZIP을 제공합니다. 사용자는 ZIP을 GitHub에 업로드하여 직접 배포합니다.

**중요한 범위 구분:** GitHub Pages의 방문자 사이트가 쿠팡 URL을 실시간 수집하거나, ChatGPT가 GitHub 저장소를 자동 수정하는 것은 아닙니다. ChatGPT 대화에서 상품 분석을 수행하고, 이 패키지의 등록 도구가 검증된 데이터를 기존 목록에 안전하게 추가하는 방식입니다. 상품 등록을 요청할 때는 최신 사이트 ZIP이나 GitHub 연결 저장소에 접근할 수 있어야 기존 상품을 보호할 수 있습니다.

### 등록 도구 (ChatGPT 또는 사용자가 실행 가능)

`tools/register_product.py`는 검증 완료한 상품 JSON 파일 1개를 입력받습니다. 상품을 분석하거나 리뷰를 직접 수집하지는 않습니다.

1. `tools/product-input-example.json`을 참고해 **실제 페이지에서 확인한 값**으로 `product-input.json`을 준비합니다. 예시는 실제 상품이 아니며 업로드 목록에 등록되어 있지 않습니다.
2. 실행 전 검사: `python tools/register_product.py --input product-input.json --dry-run`
3. 상품 추가: `python tools/register_product.py --input product-input.json`
4. `products.js`만 변경됐는지 확인한 후 GitHub에 배포합니다.

등록 시 다음 번호만 허용하며 중복 번호·동일 상품/옵션·브랜드명 노출(검수 목록 기준)·가짜 제휴 도메인·실제 파일이 없는 이미지 등을 차단합니다. 브랜드명 판별은 완전히 자동화된 의미 분석이 아니므로 ChatGPT의 검수도 필요합니다.

### 현재 001번 상품

- 공개 상품명: **서랍형 책상 정리함**
- 등록 및 검색: 적용됨
- 구매 버튼: 사용자 제공 쿠팡 파트너스 단축 URL `https://link.coupang.com/a/h1uvI4aaA0` 연결로 **활성화**. 단축 URL의 최종 이동 상품 일치는 접속 제한으로 별도 확인 필요
- 상품 이미지: 권한 있는 이미지가 없어 **도식으로 대체**
- 사이트 맨 아래 쿠팡 광고 배너: 사용자가 준 URL과 추적 파라미터를 **원본대로 유지**

## 검증에 필요한 점

- `?item=001`로 직접 검색 가능하며 `#001`, `1`, `서랍` 같은 검색도 지원합니다.
- 브라우저에서 외부 구매 링크는 HTTPS 쿠팡 파트너스 단축 링크만 활성화합니다.
- 상품 페이지의 실제 가격이나 로켓배송 여부는 변동되므로 카드에 넣지 않습니다.
- 광고 배너는 개별 001번 상품 구매 링크가 아니며, 단독 쿠팡 제휴 배너입니다.
- 상품 이미지 사용권과 광고 고지는 상품마다 검토해야 합니다.
- 새 상품 추가 때 이전 상품번호를 재사용하지 마세요.
