## R005 변경 사항
- 검색 우선의 간결한 화면으로 개편. 히어로와 '물' 아이콘 제거. 엠블럼은 색상 참고만 사용.
- 카테고리 버튼을 없애고 `전체 상품`만 표시. 상품번호·상품명·특징·내부 분류로 통합 검색.
- 모바일 2열, PC 4열 고정. 최초 12개, 더보기 클릭 시 12개 추가.
- 정렬: 최신 등록순, 오래된순, 상품번호순.
- 상품 카드: 정사각형 실물 이미지, 상품번호, 공개 상품명, 특징 한 줄, 제휴 구매 버튼.
- 상품 001 제휴 링크 및 하단 쿠팡 파트너스 광고 배너 원본 URL 보존.
- 브랜드명 공개 텍스트 노출 금지. 검색/관리용 내부 원본 데이터는 별개.

## 상품 이미지
001번 상품 카드에는 쿠팡 파트너스 상품 선택 화면에 표시된 대표 이미지 CDN URL을 연결했습니다. 외부 이미지이므로 쿠팡 측 접근 제한이 있거나 이미지 표시가 실패하면 **실제 사진 준비 중**으로 자동 전환됩니다. 별도 복제 파일은 포함하지 않았고, 공식 광고 소재 외부 재표시의 허용 범위는 운영자가 파트너스 약관에서 확인해야 합니다.
정확한 제품 사진과 사용 허락을 확인한 뒤 `assets/`에 원본을 넣고 `products.js`의 `imageUrl`을 `./assets/파일명.webp` 등으로 변경합니다.
이미지 없는 상품에 다른 제품처럼 보이는 가짜 사진이나 합성 이미지를 표시하지 않습니다.

## 쿠팡 배너 안내
쿠팡 배너는 사용자가 전달한 공식 이미지 URL과 제휴 링크를 변경하지 않았습니다. 다른 상품 사진을 별도로 추출해 사용하는 것까지 허락하는 증빙으로 간주하지 않습니다.

## 이후 상품 추가
`tools/register_product.py`는 기존 번호·중복 URL 등을 검증합니다. 다음 상품 링크로 내용을 확인한 다음 데이터만 추가해 배포 파일을 갱신하는 방식입니다.

---

### 등록 도구 (ChatGPT 또는 사용자가 실행 가능)

`tools/register_product.py`는 검증 완료한 상품 JSON 파일 1개를 입력받습니다. 상품을 분석하거나 리뷰를 직접 수집하지는 않습니다.

1. `tools/product-input-example.json`을 참고해 **실제 페이지에서 확인한 값**으로 `product-input.json`을 준비합니다. 예시는 실제 상품이 아니며 업로드 목록에 등록되어 있지 않습니다.
2. 실행 전 검사: `python tools/register_product.py --input product-input.json --dry-run`
3. 상품 추가: `python tools/register_product.py --input product-input.json`
4. `products.js`만 변경됐는지 확인한 후 GitHub에 배포합니다.

등록 시 다음 번호만 허용하며 중복 번호·동일 상품/옵션·브랜드명 노출(검수 목록 기준)·가짜 제휴 도메인·실제 파일이 없는 이미지 등을 차단합니다. 브랜드명 판별은 완전히 자동화된 의미 분석이 아니므로 ChatGPT의 검수도 필요합니다.

### 현재 001번 상품

- 공개 상품명: **서랍형 책상 정리함**
- 등록 및 검색: 적용됨
- 구매 버튼: 사용자 제공 신규 쿠팡 파트너스 단축 URL `https://link.coupang.com/a/h1NQ1AOr1M` 연결로 **활성화**. 단축 URL의 최종 이동 상품 일치는 접속 제한으로 별도 확인 필요
- 상품 이미지: 쿠팡 파트너스에 표시된 실제 상품 썸네일 주소 연결 (접근 실패 시 준비 중 안내)
- 사이트 맨 아래 쿠팡 광고 배너: 사용자가 준 URL과 추적 파라미터를 **원본대로 유지**

## 검증에 필요한 점

- `?item=001`로 직접 검색 가능하며 `#001`, `1`, `서랍` 같은 검색도 지원합니다.
- 브라우저에서 외부 구매 링크는 HTTPS 쿠팡 파트너스 단축 링크만 활성화합니다.
- 상품 페이지의 실제 가격이나 로켓배송 여부는 변동되므로 카드에 넣지 않습니다.
- 광고 배너는 개별 001번 상품 구매 링크가 아니며, 단독 쿠팡 제휴 배너입니다.
- 상품 이미지 사용권과 광고 고지는 상품마다 검토해야 합니다.
- 새 상품 추가 때 이전 상품번호를 재사용하지 마세요.
